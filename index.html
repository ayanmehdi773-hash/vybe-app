A NOTE ABOUT PRIVACY

This single-file edition stores workspace data in your browser using localStorage. It does not provide accounts, real cloud synchronisation, shared collaboration, or server-side backup. Browser data may be lost if site data is cleared. Export backups regularly. The optional Google Fonts stylesheet requires an internet connection; the app's core interface works without it.
