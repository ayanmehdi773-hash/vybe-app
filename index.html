ABOUT THIS VERSION

VYBE OS — Personal Workspace

This is a browser-based frontend. It supports local notes, tasks, projects, planning, focus sessions, app shortcuts and JSON backup/restore. It does not provide user accounts, server storage, cross-device sync, shared workspaces or real-time collaboration. Never use it to store passwords or highly sensitive information.
