# ⚡ VYBE — Silicon Valley Grade Web OS & Productivity Suite

A lightning-fast, privacy-first single-file web OS and productivity launcher dashboard featuring a dark mode glassmorphism UI.

🔗 **Live Demo:** [vybe-app-beta.vercel.app](https://vybe-app-beta.vercel.app/)

---

## 🚀 Features

- **Glassmorphism UI:** Modern, sleek, and immersive dark mode design.
- **Task Master:** Manage your daily tasks efficiently.
- **Notes:** Quick-access note-taking interface.
- **Focus Room:** Built-in tools to boost your productivity.
- **Image Studio:** Light and fast image tools right inside your browser.
- **Single-File Architecture:** Built with clean, optimized HTML, Tailwind CSS, and JavaScript.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla)
- **Icons:** FontAwesome
- **Fonts:** Inter & JetBrains Mono
- **Hosting & Analytics:** Vercel
